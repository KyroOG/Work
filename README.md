# Work v4

A local-first productivity app with tasks, independent alarms, Pomodoro focus, settings, import/export, responsive navigation, accessible controls, and a PWA shell.

## Run

Open `index.html` directly for the local/offline experience. PWA installation and service-worker features require a secure web origin such as HTTPS or localhost.

## Publish

Upload the four files in this folder to any static HTTPS host. No build step or external dependencies are required.

## Data

Workspace data is stored in browser `localStorage` under `work.v4`. Use Settings → Export Workspace before moving browsers/devices.
